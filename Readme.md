# Implementacion Realidad Aumentada 

En este proyecto se implementa la RA desde la web.

## Introduccion

"AR.js V2 introdujo la realidad aumentada basada en la ubicacion en la web. Esto permite nuevas experiencias en la realidad aumentada".


## Objetivo:

Implementar WebGL y WebXR con A-frame, Three.js, AR.js y (GeoAR.js) LocAr.js para geolocalizacion, para el desarrollo de un App de realidad Aumentada basada en la localizacion (Based Locatioon).

## Metodologia 

Para el desarrollo final de la app de RA para conectar el juego tipo "Busqueda del tesoro", y su aplicacion sera vista al momento de llegar a unas coordenadas o ubicacion.
En este momento se abre la aplicacion pidiendo permisos de ubicacion y uso de camara y se buscara el objeto en la ubicacion este se mostrara en realidad Aumentada con una animacion.

### Librerias:
    - A-Frame 
    - AR.js 
    - GeoAR.js / LocAR.js
